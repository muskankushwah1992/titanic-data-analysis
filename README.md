# Titanic Data Analysis

## Objective
Is project ka maqsad Titanic dataset ka exploratory data analysis (EDA) karke passenger survival factors ko samajhna hai.

## Libraries Used
* Pandas
* NumPy
* Matplotlib / Seaborn

## Key Insights
* Passenger class aur gender ka survival rate par bada asar tha.
* Women aur children ke survival chance zyada the.
